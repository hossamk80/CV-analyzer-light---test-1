# Talenta — AI CV Screening Suite · Complete Implementation Prompt

> Hand this document to an AI coding agent as the full specification. Nothing outside this document should be invented; nothing inside it should be skipped.

---

## 0. Stack assumptions

- Single-page app, client-side routing between screens (no full page reloads).
- All styling is **token-driven inline styles or utility-free CSS custom properties**. No hard-coded colors in components.
- Icons are **inline SVG only** (24×24 viewBox, `fill="none"`, `stroke="currentColor"`, `stroke-width` 1.8–2.2, round caps/joins). Never load an icon-font or a runtime icon library that mutates the DOM.
- Charts are hand-built inline SVG (`viewBox` + `width:100%`). No chart library required.
- Fonts: **Inter** (Latin UI) + **Noto Sans Arabic** (Arabic). Weights 400/500/600 only.

## 2. Design language

**Character:** quiet, premium, technical. Contrast comes from tonal steps, not saturation. The accent appears as lines, hairlines, glows, small tinted fills and data marks — **never as a large flood**, the single exception being a selected control (theme pill, swatch).

**Type scale**
- page title `clamp(21px, 2.4vw, 30px)`, weight 500, `letter-spacing: -.02em`
- panel title 17px / sub-panel title 15–16px, weight 500
- card title 13.5–15.5px
- body 12.5–13px, line-height 1.6–1.75
- micro label 10–11px, weight 600, uppercase, `letter-spacing: .14em` (kicker `.22em`)
- big numbers `clamp(24px, 2.6vw, 32px)`, weight 500, `letter-spacing: -.03em`
- **every numeral** uses `font-variant-numeric: tabular-nums`
- monospace (`ui-monospace, SFMono-Regular, monospace`) for model names, API keys, URIs, prompt bodies, filenames

**Shape:** panels `border-radius: 18px` · tiles 16px · inner tiles/rows 11–13px · controls 9–12px · pills, bars and switch tracks 99px · avatars 50%.

**Elevation:** dark themes = 1px border + gradient surface, `--tk-shadow: none`. Light theme = the same border plus `0 2px 12px rgba(24,26,38,.07)`. Popovers only may use `0 22px 50px rgba(0,0,0,.35)`.

**Motion:** state changes only, 180–200ms ease (active nav mark height, switch knob offset). No entrance animation, no parallax, no hover lift.

**Never:** emoji, decorative illustration, rainbow gradients, headings bolder than 500, pure `#000`/`#fff` as a surface, heavy stacked shadows on dark.

## 3. Theme engine (core requirement)

Two inputs drive every color in the app, set as CSS custom properties on the app root:

- `theme` ∈ `light` | `dark` | `midnight` (default `dark`)
- `accent` ∈ 7 swatches (default violet `#8b5cf6`)

```
Blue #3b82f6 · Emerald #10b981 · Violet #8b5cf6 · Orange #f97316
Pink #ec4899 · Red #ef4444 · Amber #f5b301
```

### 3.1 Accent-derived tokens (theme-independent)

```css
--tk-accent:        <chosen hex>;
--tk-accent-soft:   color-mix(in srgb, var(--tk-accent) 16%, transparent);
--tk-accent-mid:    color-mix(in srgb, var(--tk-accent) 42%, transparent);
--tk-accent-line:   color-mix(in srgb, var(--tk-accent) 52%, transparent);
--tk-accent-strong: color-mix(in srgb, var(--tk-accent) 72%, transparent);
--tk-on-accent:     /* computed, see 3.2 */;
```

Roles: `soft` = tinted fill (chips, active nav, score chips) · `mid` = gradient start, histogram low bars, radial bloom · `line` = borders of outlined primaries, hover borders, hero border · `strong` = the 1px top hairline on tiles.

### 3.2 `--tk-on-accent` — computed, never per theme

Foreground for anything filled with the raw accent (selected theme pill, logo glyph, swatch check, switch knob, RBAC checkbox tick). Compute from the accent's own relative luminance and pick the **higher-contrast** of two candidates:

```js
const lin = c => (c <= 0.03928 ? c/12.92 : Math.pow((c+0.055)/1.055, 2.4));
const lum = 0.2126*lin(r/255) + 0.7152*lin(g/255) + 0.0722*lin(b/255);
const cr  = (a,b) => (Math.max(a,b)+0.05)/(Math.min(a,b)+0.05);
onAccent  = cr(lum, 0.0086) >= cr(lum, 1) ? '#14161f' : '#ffffff'; // 0.0086 = luminance of #14161f
```

**Page background** — layered accent-tinted glow over the solid:

```css
/* dark */
radial-gradient(1200px 600px at 12% -8%, color-mix(in srgb, var(--tk-accent) 20%, transparent), transparent 60%),
radial-gradient(900px 500px at 92% 4%, rgba(96,120,190,.12), transparent 62%),
var(--tk-page-solid)
/* light: 14% + 7%, two glows · midnight: one 15% glow */
```

**Rules**
- `--tk-accent-text` (a mixed step) is what carries accent-colored **text**; the raw accent is for chrome, marks and fills only.
- Entering Midnight sets the accent to Amber by default; any swatch may then be chosen. In Midnight all borders and dividers are accent-tinted, so the chrome glows in the accent hue over near-black.
- Mirror the tokens into any consumed design-system variables (`--color-accent`, `--color-bg`, `--color-surface`, `--color-text`, `--color-divider`).
- Sync `document.body.background` to `--tk-page-solid` so overscroll matches.
- Persist `theme` + `accent` (localStorage or user profile) and expose both as component props so they can be driven externally.

## 15. Behaviors

- **Navigation** — the rail selects screens 0–7 and drives the header kicker/title. Cross-links: dashboard *View leaderboard* → 3, dashboard/jobs **New job** → 9, candidate **Open** (dashboard + leaderboard) → 8, job **Results** → 3. Screens 8 and 9 show a back link (8 → 3, 9 → 1) and never appear in the rail.
- **GDPR anonymization** — header toggle. When on, every candidate name across the AI panel, top candidates, leaderboard and report becomes `Candidate #1041`, `#1042`, … (index-based, stable), and the *Anonymize personal data* switch on screen 2 reflects the same state. The button itself takes the accent-soft active treatment.
- **Language** — flips `dir` to `rtl`, swaps every string, converts counts and analytics figures to Arabic-Indic digits (`toLocaleString('ar-EG')`), and mirrors directional glyphs with `transform: scaleX(-1)`. Prompt bodies, URIs, emails, model names and filenames stay `dir="ltr"`. Use logical properties everywhere (`inset-inline-start`, `margin-inline-start`, `border-inline-end`, `padding-inline-start`) so RTL needs no second stylesheet.
- **Chart range** — the 7/30-day segment swaps dataset, curve, dot visibility and tick density.
- **Job filter** — All / Open / Paused filters the job grid; Paused currently matches one job.
- **Settings tabs** — independent of screen state; the selected tab persists while the user navigates away and back.
- **Theme + accent** — apply instantly to every screen, persist, and re-derive `--tk-on-accent`.

## 16. Responsive rules

- No fixed page widths. Every multi-column section is `repeat(auto-fit, minmax(200–330px, 1fr))` so 4 → 2 → 1 column happens with **no media queries**.
- Type, panel padding and chart height scale with `clamp()`.
- Every row (header cluster, candidate rows, provider rows, audit rows, card footers) is `flex-wrap: wrap` with `flex-basis` minimums, so cells reflow instead of truncating to nothing.
- Long strings truncate inside `min-width: 0` flex children (`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`).
- Charts are `viewBox`-based SVG at `width: 100%`; bars use percentage heights inside a fixed-height flex row.
- The rail narrows with `clamp(60px, 6vw, 76px)` and keeps 44px targets; inline row actions stay ≥ 30px.
- Wide data tables (leaderboard, audit) reflow rather than horizontally scroll; if a horizontal scroll is unavoidable, keep the rank + name cell pinned.

---

## 17. Accessibility

- Body text ≥ 4.5:1 in all three themes. Accent-colored text always uses `--tk-accent-text`, never the raw accent on a panel.
- Every accent-filled surface takes its foreground from the computed `--tk-on-accent` (§3.2).
- `:focus-visible { outline: 2px solid var(--tk-accent); outline-offset: 2px; }` on every interactive element — never remove focus rings.
- Icon-only buttons carry `title` + `aria-label`; switches and toggles expose `aria-pressed`/`aria-checked`; tabs use `role="tab"` + `aria-selected`; the appearance popover is dismissible with `Esc` and returns focus to the palette button.
- Status is never color-only — every pill carries a text label.
- Touch targets ≥ 44px in the rail, ≥ 30px for inline row actions.
- Respect `prefers-reduced-motion`: drop the two state transitions.

## 18. Definition of done

1. All three themes × seven accents render with no hard-coded color anywhere and no sub-AA text.
2. All ten screens are reachable, including both drill-downs and their back links.
3. Arabic mode mirrors the entire layout with no clipped or reversed technical strings.
4. GDPR masking affects every surface that shows a candidate name.
5. Every prefilled input is typeable; no controlled input lacks a change handler.
6. No console warnings; no runtime library mutates DOM nodes owned by the framework.
7. From 1920px down to 360px, no horizontal page scroll and no overlapping content.
